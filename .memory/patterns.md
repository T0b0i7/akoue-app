# Patterns

- Expo Router: tabs dans `app/(tabs)/`, modals dans `app/(modals)/`, auth dans `app/(auth)/`
- Co-localiser composants métier dans `components/`, logique métier dans `services/` et `context/`
- Validation avec `zod`, typage strict TS
- Pas de `any` implicite
